# 勤務表作成 PWA

このフォルダをHTTPSで配信できる場所にそのまま配置すると、スマホでホーム画面に追加して使えます。

- PDFの読み取りとExcel作成はブラウザ内で行います。
- PDFはサーバーへアップロードしません。
- 年月はPDFから自動で読み取り、画面に表示します。
- 所属会社とプロジェクト名の初期値は空欄です。
- 一度出力に使った所属会社とプロジェクト名は、その端末のブラウザ内に候補として保存されます。
- 初回表示と更新時は通信が必要です。
- 一度表示してホーム画面に追加した後は、キャッシュ済みの範囲でオフライン利用できます。

スマホで使う流れ:

1. このフォルダの中身をHTTPSの静的サイトへアップロードします。
2. GitHub Pagesの場合は、`index.html` がリポジトリの一番上に来るように配置します。
3. スマホのブラウザでURLを開きます。
4. iPhoneは共有メニューから「ホーム画面に追加」、Androidはブラウザメニューから「アプリをインストール」または「ホーム画面に追加」を選びます。
5. ホーム画面のアイコンから開き、PDFを選んで勤務表を出力します。
